
# CivicFix AI

A local-first AI agent for intelligent civic complaint management using an open-weight model through Ollama.

## Features
- AI-powered civic complaint analysis
- Complaint categorization and severity recommendations
- Duplicate complaint detection
- Department routing
- Ticket creation and status tracking

## Tech Stack
- React + Vite
- Node.js + Express
- Ollama with a locally running open-weight model
- JSON or SQLite for ticket persistence

## Project Structure
- `frontend/` — React user interface
- `backend/` — Express API and ticket management
- `ai/` — Local model integration and agent tools
